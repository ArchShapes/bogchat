Database (optional, free)

How to set it up (free, about 5 minutes)
  1. Go to console.firebase.google.com, create a project (the free Spark plan is enough).
  2. Build → Realtime Database → Create database. Copy the URL shown at the top into Database URL.
  3. Build → Authentication → Get started → Email/Password: turn it on. Then open the Users tab and Add user with an email and password only you know.
  4. Project settings (gear) → General → Web API key: paste it into Web API key.
  5. Realtime Database → Rules: paste the rules below and press Publish. They let only your email read or write.
  6. Tick the box, press Test database, then Save & start.

Nothing secret is inside this .html file. The URL, key, email and password are kept only in this browser, and only the signed-in email can read or write the data. With the database on, cookies are no longer reset at every launch.
